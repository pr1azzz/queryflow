## 3. Индивидуальный сквозной проект

- **Название:** QueryFlow — система учета вопросов и ответов  
- **Предметная область:** учёт вопросов и ответов (User, Question, Answer, Category)  
- **Перечень функций ПР2 (основные):**
  - `categories.py`: `add_category`, `find_category`, `is_category_active`, `filter_active_categories`, `sort_categories` (lambda);
  - `questions.py`: функции ПР1 (`can_publish_question`, `get_question_status`, `format_question_card`) и ПР2 (`add_question`, `find_questions`, `filter_questions_by_category`, `filter_open_questions`, `sort_questions_by_date`, `close_question`, `get_question_by_id`);
  - `answers.py`: `add_answer`, `get_answers_for_question`, `count_answers`, `remove_answer`;
  - `users.py`: `add_user`, `find_users`, `get_user_name`, `normalize_role`;
  - `storage.py`: `load_json` / `save_json`, `load_*` / `save_*` (JSON через `with`, обработка `FileNotFoundError` / `JSONDecodeError`);
  - `utils.py`: `input_int`, `input_nonempty`, `input_choice`, `configure_console`;
  - `main.py`: `main()` — цикл меню и сценарии взаимодействия.
- **Структура модулей:**
  ```
  queryflow/
  ├── main.py
  ├── categories.py
  ├── questions.py
  ├── answers.py
  ├── users.py
  ├── storage.py
  ├── utils.py
  ├── requirements.txt
  ├── README.md
  ├── data/          # categories.json, users.json, questions.json, answers.json
  └── tests/         # test_categories.py, test_questions.py, test_answers.py
  ```
- **Формат хранения данных:** JSON-файлы в каталоге `data/` (списки словарей; категории и пользователи при загрузке приводятся к `dict[int, dict]`).

## 4. Результат работы

В результате выполнения ПР2:

- завершены темы раздела 01 (коллекции, циклы, проект «Холодильник») и материалы раздела 03, указанные в методичке;
- код проекта разделён на логические модули по предметной области;
- данные переведены в JSON-файлы и загружаются при запуске;
- реализованы функции обработки коллекций (поиск, фильтрация, сортировка), проверка возможности публикации, добавление/закрытие вопросов и ответов, меню сценариев;
- обработка исключений защищает программу при некорректном вводе и ошибках чтения JSON;
- основные функции снабжены аннотациями типов и docstring;
- выполнены тестирование (`pytest`: 11 тестов) и проверка оформления (`flake8` без замечаний);
- обновлён `README.md`; результат зафиксирован в локальном Git-репозитории.

## 5. Вывод

В ходе ПР2 сквозной проект QueryFlow превращён из одиночного сценария ПР1 в модульную консольную программу с коллекциями, JSON-хранилищем, меню и автотестами. Это подготавливает переход к ПР3 (ООП: классы User, Question, Answer, Category) и дальнейшей веб-реализации на Django.
