## 3. Индивидуальный сквозной проект

- **Название:** QueryFlow — система учета вопросов и ответов  
- **Функции ПР2 (основные):**
  - категории: `add_category`, `find_category`, `is_category_active`, `filter_active_categories`, `sort_categories`;
  - вопросы: `can_publish_question`, `get_question_status`, `format_question_card` (из ПР1), `add_question`, `find_questions`, `filter_questions_by_category`, `close_question`, `sort_questions_by_date`;
  - ответы: `add_answer`, `get_answers_for_question`, `count_answers`;
  - пользователи: `add_user`, `find_users`, `get_user_name`;
  - хранение: `load_*` / `save_*` для JSON;
  - ввод: `input_int`, `input_nonempty`;
  - интерфейс: меню в `main()` и функции вывода.
- **Структура модулей:**
  ```
  queryflow/
  ├── main.py
  ├── categories.py
  ├── questions.py
  ├── answers.py
  ├── users.py
  ├── storage.py
  ├── utils.py
  ├── requirements.txt
  ├── README.md
  ├── data/          # categories.json, users.json, questions.json, answers.json
  └── tests/         # test_categories.py, test_questions.py, test_answers.py
  ```
- **Формат хранения данных:** JSON-файлы в каталоге `data/` (списки/словари сущностей предметной области).
