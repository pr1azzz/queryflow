## 3. Индивидуальный сквозной проект

- **Название проекта:** QueryFlow — система учета вопросов и ответов  
- **Предметная область:** учёт вопросов и ответов пользователей (Q&A): публикация вопросов по категориям, ответы, статусы обсуждения  
- **Основные сущности:** пользователь (User), вопрос (Question), ответ (Answer), категория (Category)  
- **Реализованный на ПР1 функционал:** начальный консольный сценарий с тремя функциями (сохранены и используются в текущей версии проекта в модуле `questions.py`):
  1. `can_publish_question` — проверка возможности публикации вопроса;
  2. `get_question_status` — определение статуса вопроса;
  3. `format_question_card` — формирование краткой карточки вопроса.  
  Используются простые типы данных, операции, преобразование типов, ветвления, функции и импорт модуля `datetime.date`.
