# QueryFlow — Система учета вопросов и ответов

Консольное приложение для учёта вопросов и ответов пользователей:
публикация вопросов по категориям, ответы, статусы обсуждения.

## Возможности

- просмотр и поиск категорий;
- публикация вопросов с проверкой длины текста и активности категории;
- поиск и фильтрация вопросов;
- добавление ответов;
- определение статуса вопроса (открыт / закрыт / ожидает ответа);
- закрытие вопроса;
- учёт пользователей;
- сохранение данных в JSON.

## Целевая аудитория

- студенты и преподаватели;
- участники учебных проектов и внутренних FAQ;
- администраторы категорий и статусов.

## Предметная область

Учёт вопросов и ответов (Q&A). Пользователи задают вопросы, относят их
к категориям и получают ответы.

## Основные сущности

- **Пользователь (User)** — автор вопроса или ответа (имя, роль);
- **Вопрос (Question)** — текст, категория, статус, автор;
- **Ответ (Answer)** — текст, связь с вопросом, автор;
- **Категория (Category)** — тематическая группа (название, активность).

## Основные функции

- `can_publish_question` — проверка возможности публикации;
- `get_question_status` — статус вопроса;
- `format_question_card` — краткая карточка вопроса;
- добавление/поиск категорий и вопросов;
- добавление ответов и подсчёт их числа;
- загрузка/сохранение данных в JSON.

## Структура проекта

- `main.py` — точка запуска и меню;
- `categories.py` — работа с категориями;
- `questions.py` — работа с вопросами (включая функции ПР1);
- `answers.py` — работа с ответами;
- `users.py` — работа с пользователями;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — безопасный ввод;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.
